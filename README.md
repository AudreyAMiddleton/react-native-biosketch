# BioSketch

BioSketch is a cross-platform profile application built with React Native, Expo, and JavaScript as part of graduate coursework in Software Engineering and Multiplatform App Development at the University of the Cumberlands.

## Description

The application presents a structured biographical profile with information about professional background, academic interests, and career goals. The project provided hands-on experience building a mobile-style interface with React Native components and organizing application content within a cross-platform development environment.

## Features

- Personal profile and biographical information
- Professional background section
- Academic interests section
- Career goals section
- Profile image and formatted content layout
- Cross-platform application structure using React Native and Expo

## Technologies Used

- JavaScript
- React Native
- Expo
- JSX
- Git
- GitHub

## Project Structure

- `App.js` — main application interface and content
- `index.js` — application entry point
- `app.json` — Expo application configuration
- `package.json` — project dependencies and scripts
- `assets/` — application images and media

## Learning Focus

This project provided experience with:

- React Native component structure

- Application layout and content organization
